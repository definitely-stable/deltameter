# M6-D11 — fixed-constant polynomial reduction experiment

Issue: #45. Parent: #19 / #14.  
Base: D10 merge `a0c860bd8071927e0f586cb00371ebb25af9ed0f`.  
Scope: one private reduction-only experiment.

## Causal hypothesis

D10 measures net polynomial reduction at 88.299-92.428% of post-D8 square/mod
across all five d=8 corpora. During one factor frame, reduction repeatedly multiplies
changing leading factors by the same fixed modulus coefficients.

D11 tests whether exploiting that fixed-constant structure produces material
end-to-end gain after paying real plan-construction cost.

## Candidate

For each degree>=3 monic factor frame, build one ephemeral `ReductionPlan`.

For each modulus coefficient the plan stores 16 positional nibble tables × 16
entries. Basis images are generated by repeated multiply-by-x in the frozen
polynomial basis. Multiplication of a variable factor by that fixed coefficient is
then 16 indexed XORs.

The plan exists only for the factor frame. It is not public, persisted, shared,
cached globally or written into snapshot state.

Only trace square/mod polynomial reduction uses the plan. Frozen generic
`gf64_mul` remains in normalization, inversion, GCD and polynomial division.

## Correctness gates

- fixed multiplier == frozen generic multiplication on all 64 variable basis
  vectors for edge/deterministic constants;
- at least 4096 deterministic variable/constant pairs agree;
- D11 result/error == accepted D8 at every k stage across five corpora and the full
  d matrix;
- successful d<=8 == exact symmetric-difference oracle;
- d=9/10/16 remain reject;
- zero/high-bit/u64::MAX and invalid-limit/guard ordering remain frozen.

## Performance matrix

~~~text
corpora = d4,d5,d6,d7a,d7b
d = 0,1,2,3,4,5,8,9,10,16
samples/process = 4 balanced D8/D11 order
hosted processes = 3
~~~

The timed candidate includes actual `ReductionPlan` construction.

## Frozen acceptance gate

ACCEPT for private research only when all hold:

- each d=8 corpus paired median reduction >=10.0%;
- aggregate d=8 paired median reduction >=15.0%;
- every per-process d=8 paired median >0%;
- d=3/4/5: no corpus paired median < -2.0%;
- logical/correctness gates pass and false-success total = 0.

d=0/1/2 are control/noise lanes.

If the gate fails, reject D11 and stop algebraic decoder micro-optimization.

No unsafe, SIMD/CLMUL, FFI, nightly, dependency, field representation, protocol,
public API or production promotion.

Production/public ExactSmallDelta remains NO-GO.
