# DeltaGuard G1-A — prior-allocated per-level alpha recalibration (research only)

Issue #85 (G1-A) and #84 (DeltaGuard); compatible with merged G0 PR #87.
**PRE-REGISTERED BEFORE GENERATING NEW TABLES OR OBSERVING POWER.**

## Actual model and fixed selection

Same unchanged m=4096 keyed-BLAKE3 token-to-(row,level,bit)
map, same J52 physical oracle semantics and exact full-u64
fallback as G0. Each two-party state independently maintains
only k selected levels with k∈{1,2,4}. Levels are selected by
the G0 deterministic CENTER T-only policy **before processing input**
and remain fixed over both producers' sketch lifetimes.

Total statistical failure budget δ=1/1,000,000, with ex-ante
per-selected-level α=δ/k (k=1,2,4). This is *NOT* the
original δ/64 Q32 table. Each k uses its own lookup table
generated by a high-precision numeric proposal and proved
conservative by an **independent integer/rational verifier**
for EVERY one of the 2,048 observation counts, with a
distinct SHA256 table digest; non-finite Q32 sentinel is
checked at the p→1/2 limiting law. The old δ/64 certificate
remains the control. The independent proof validates finite
crossings using lower Taylor enclosure on
p(q)=(1-exp(-q/(2^32*m)))/2 and exact likelihood ratios.

For each fixed predetermined T and k under independent ideal
oracle and fixed nonadaptive token pair A,B:
  Pr_d[U_j<d] <= δ/k for each of the k selected levels;
  Pr_d[min_selected U_j < d] <= sum_selected δ/k = δ;
  for d>T, Pr_d[SAFE_BELOW_T] <= δ.
Proof is the classical union bound, not a novel theorem.
A wrong profile/table, table digest or selected level identity
is a hard error. This is **NOT** a uniform guarantee for
arbitrarily adaptively changing T/k on an already observed
sketch. Even if all k-specific tables are predeclared,
simultaneous cross-profile coverage would require separately
budgeting for all queried profiles. The keyed BLAKE3 PRF
computer-security assumption remains separate from
ideal-oracle finite-sample statistics.

## Quantitative gates, frozen in advance

- G1A_CERT_PASS: **all 3** k=1/2/4 fresh tables
  independently integer/rational certified; reject
  nonfinite/bad tail and all accidental reuse of original table.
- G1A_ALGEBRA_PASS: all source/selected word equality tests
  and complete 900 paired rows verified across all 5
  hosted workers; no race/missing/mismatched head.
- G1A_USEFULNESS_CANDIDATE: at T=64,d=0.25T,
  at least 12/15 fixed-key deterministic rows newly
  respond SAFE (selected best k), OR at T=4096,d=0.75T,
  at least 12/15 newly respond SAFE.
  This is a *falsification/power discovery gate*, NOT a
  rare-failure estimate or randomized-key statistical power
  certificate.
- If certification passes but utility does not,
  **G1A_CERT_PASS_LOW_POWER**; do not fabricate a
  product win and move to a newly scoped, exact
  small-m or exact fixed-d distribution study.
- Explicitly preserve the known G0 negative: T64 0/15
  for 8 original levels at d=.25T. Do not hide if improved
  calibration still fails.
- No public API, no snapshot update, no automatic
  adoption of per-k alpha for repeatedly queried
  sketches, no new proof of computational/adaptive safety.
